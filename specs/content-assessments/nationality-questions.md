# Nationality questions

Current status, 2026-10-29: the independent audit required corrections. The
[current correction assessment](question-words-corrections.md) supersedes the
final approval below for version 1.1.0; the dated original record is retained.

`nationality-questions`, version `1.0.0`, level `0 - A1.3`.

Two lessons cover singular and plural nationality questions and replies. See the
shared [blueprint, sources, both pedagogy decisions and final evidence](question-words-family.md).
This pack owns 48 scored questions and six independent optional items. Nationality
is distinguished from residence and origin; no nationality is inferred from those
facts alone. Existing packs and compatible progress remain unchanged; no migration
or reset is introduced.
