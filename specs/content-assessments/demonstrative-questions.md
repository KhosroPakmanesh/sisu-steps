## Important-skill coverage and sequence

1. Ask what one referent is with the bounded frame `Mikä tämä on?`.
2. Ask what several referents are with the bounded classification frame `Mitä nämä ovat?`.
3. Build singular affirmative yes/no questions with `Onko ...?`.
4. Build plural affirmative yes/no questions with `Ovatko ...?`.
5. Build singular negative yes/no questions with `Eikö ... ole?`.
6. Build plural negative yes/no questions with `Eivätkö ... ole?`.

The Review combines only these six question types. General `mikä`/`mitä`/`mitkä` selection and short answers are excluded.
