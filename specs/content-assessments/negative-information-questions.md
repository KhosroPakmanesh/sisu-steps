# Negative information questions and answers

Current status, 2026-10-29: the independent audit required corrections. The
[current correction assessment](question-words-corrections.md) supersedes the
final approval below for version 1.1.0; the dated original record is retained.

`negative-information-questions`, version `1.0.0`, level `0 - A1.3`.

Seven lessons cover singular/plural negative olla and action questions,
nobody/nothing replies and affirmative correction of an assumed negative. See the
shared [blueprint, sources, both pedagogy decisions and final evidence](question-words-family.md).
This pack owns 168 scored questions and 21 independent optional items. Negative
questions are distinct from negative replies and from already taught negative
yes/no questions. Existing packs and compatible progress remain unchanged; no
migration or reset is introduced.
